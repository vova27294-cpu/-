# Хроники — запускаемый прототип (Vite + React)

Это тот же прототип v0.1, что был в чате (`App.jsx`, `api.js`, `gameData.js`, дизайн и игровая логика не менялись), но теперь упакован как обычный запускаемый проект: Vite + React + Tailwind + lucide-react.

Backend, PostgreSQL, PvP — сознательно не добавлены (как и просили). Все действия (пул карт, магазин, игры, Оракул) работают через локальную симуляцию в `src/api.js`, как и раньше.

## Структура проекта

```
hroniki/
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
├── .gitignore
└── src/
    ├── main.jsx      — точка входа
    ├── index.css     — подключение Tailwind
    ├── App.jsx        — экраны, модалки, состояние
    ├── api.js         — клиент API + локальная симуляция сервера
    └── gameData.js    — персонажи, редкости, игры, паки
```

## Пошаговый запуск на Windows

### 1. Установи Node.js (если ещё не установлен)

1. Зайди на **https://nodejs.org**
2. Скачай версию **LTS** (рекомендуемая, сейчас это 20.x или новее — подойдёт любая версия от 18 и выше).
3. Запусти установщик, везде жми «Далее» с настройками по умолчанию.
4. После установки **перезапусти** все открытые окна терминала (или перезагрузи компьютер, если что-то не заработает).
5. Проверь, что всё встало: открой **PowerShell** (Пуск → напиши «PowerShell» → Enter) и введи:
   ```
   node -v
   npm -v
   ```
   Должны напечататься номера версий (например `v20.15.0` и `10.7.0`). Если пишет «не является внутренней или внешней командой» — Node не установился или нужен перезапуск терминала/компьютера.

### 2. Распакуй архив проекта

1. Скачай `hroniki.zip` из чата.
2. Правой кнопкой → **«Извлечь всё…»** → выбери папку, например `Документы\hroniki`.
3. Убедись, что после распаковки внутри папки сразу лежит `package.json` (а не ещё одна вложенная папка `hroniki` — если так получилось, зайди на уровень глубже).

### 3. Открой терминал в папке проекта

Самый простой способ:
1. Открой папку `hroniki` в Проводнике.
2. В адресной строке Проводника (сверху) напиши `powershell` и нажми Enter — откроется PowerShell сразу в этой папке.

(Альтернатива: открой PowerShell и введи `cd` и путь к папке, например `cd Документы\hroniki`.)

### 4. Установи зависимости

В открытом терминале выполни:
```
npm install
```
Это скачает React, Vite, Tailwind и lucide-react (займёт от нескольких секунд до пары минут в зависимости от интернета). Дождись, пока команда полностью завершится и вернётся приглашение ввода.

### 5. Запусти приложение

```
npm run dev
```
В терминале появится что-то вроде:
```
  VITE v5.x.x  ready in xxx ms
  ➜  Local:   http://localhost:5173/
```
Открой этот адрес (`http://localhost:5173/`) в браузере — увидишь «Хроники».

### 6. Останови сервер, когда закончишь

В терминале нажми **Ctrl + C**.

### Дополнительно: production-сборка

Если позже понадобится собрать оптимизированную версию для реального хостинга:
```
npm run build
```
Создаст папку `dist/` со статическими файлами. Проверить её можно так:
```
npm run preview
```

## Если что-то не заработало

- **`npm install` зависает или выдаёт ошибку сети** — проверь интернет/VPN/файрвол, попробуй ещё раз.
- **Белый экран в браузере** — открой консоль браузера (F12 → вкладка Console) и пришли мне текст ошибки.
- **Порт 5173 занят** — Vite сам предложит другой порт (например 5174), просто открой адрес, который он напечатает.
- **`node -v` не работает после установки** — перезагрузи компьютер, это чаще всего решает проблему с PATH.
